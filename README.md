# Crash Research Lab

Independent research into whether Crash multiplier histories contain out-of-sample predictive signals. No wagering automation or guaranteed predictions.

## Research protocol

- Import legally obtained CSV data, preserving chronological order and source provenance.
- Compare a constant-probability baseline with lag-based models.
- Evaluate on unseen later rounds with Brier scores, avoiding data leakage.
- Report negative findings as well as positive ones.

This is a research project, not a betting strategy.
